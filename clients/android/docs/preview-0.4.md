# 栖卷 Android 0.4 预览

版本 0.4.0-preview，versionCode 6，Android 10+，arm64-v8a / x86_64。
应用名为“栖卷”，采用明亮蓝渐变和叠层机架图标，保持原包 ID 与签名身份。
这是 debug 预览；正式版性能和完整体验验收继续执行。

## 包含的产品能力

- Media3 1.11.1 原生播放器、FFmpeg 音频扩展、libass 字幕覆盖层。
  视频输出与控件/字幕保持独立；媒体代次隔离迟到事件，音轨/字幕请求确认与错误反馈。
- 字幕时间偏移、普通文本外观、ASS 作者样式、NAS/本地 SAF 外挂、SUP/PGS 外挂。
  外挂文件完整解析后才选中；支持 seek 缓冲期间添加，时间调整保留暂停意图。
  外挂读取上限16 MiB；SUP 位图/文本 cue 保留上限32 MiB及20,000条事件，超过预算明确失败。
- 硬件优先/仅硬件/软件策略、实际解码器和片源信息、受控的一次软件恢复尝试。
  实际 HDR 输出未取得证明时保留“未验证”。
- 当前结果快照的图片/视频队列、Telephoto 缩放和大图细节、原图请求与取消、GIF 动画。
- 分区双击、长按临时倍速、左右亮度/媒体系统音量、方向与触控锁。
- 无法播放时的缓冲百分比、持续显示的真实下载速度、图片读取圆环百分比。
  拖动进度条请求现有 NAS sprite 缩略图，读取失败仍显示目标时间。
- 五种文件布局、类别/排序、搜索范围、所在目录跳转、完整文件详情。
- 服务端收藏列表、分组/颜色/顺序、收藏改名与移动、文件/目录及搜索结果收藏入口。
  服务端 ID 和路径为权威；页面刷新读取其它客户端的变更，切账号清空并隔离旧请求。

## 预览验证边界

Android build/lint/unit gates与已审计的小米14聚焦测试分别记录。
此前真实手机证明包含字幕像素/ASS/PGS、暂停与 seek、分区手势、图片队列和GIF连续换帧。
预览发布回执记录本次实际测试结果与对应源码，不把未运行项目记成通过。

仍需完成：完整 API35/API37 回归、真实 NAS/Web 收藏双向验收、全页视觉/TalkBack、
真实声音切轨/倍速连续性、HDR 输出证明、LAN/tsnet性能、长片/整片、故障恢复压力测试。
SAMI 外挂、标签、回收站、存储工具、服务端任务中心和可离线播放/边下边播下载仍在后续切片；
预览未提供这些能力。

## 交付、许可与升级

公开预览绑定已推送的明确源码SHA，提供同证书APK及最终SHA256、FFmpeg和libass
对应源码包。详见 `licenses/media3-probe.md` 与 native build recipe。
原0.3可直接覆盖升级，保留档案、Room数据、缓存偏好和内嵌节点；不卸载或清数据。
0.4不改变Room schema5。回退不能假定APK降级允许；需要时交付同证书、更高versionCode
的回退修复包。旧0.3 APK与源码仍保留，不覆盖历史发行。
