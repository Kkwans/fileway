# Android 0.2界面验收预览

此次预览用于尽早验证真实手机上的界面方向，不代表正式版验收完成。
Android 10+(API29)，arm64-v8a/x86_64，versionCode 2，版本0.2.0-preview。
构建和下载的明确源码SHA、签名及校验和随GitHub预发布说明提供。

## 变化

- 文件四种布局：封面网格、大图列表、常规列表、紧凑网格。每项小圆角卡片，统一边距、浅灰背景，减少无效留白；小缩略图不再重叠显示占位文字。
- 搜索直接复用NAS增量接口，支持当前目录/子目录、取消、重试和详情，结果使用同一文件卡片。
- NAS缩略图经会话绑定的Go/JNI入口与Coil显示，未授权内容不进入图片URL；暂无缩略图如实显示。
- 设置按外观、服务器与连接、存储、应用分组，一组一个10dp圆角卡片、一项一行。主题跟随系统/明/暗持久化。
- 此前的播放器全屏视口、字幕控制、续播改进也包含在内。

## 安装验收

下载发布页APK，允许相应来源安装。使用与首版同一专用签名，版本号提高，可从首版覆盖升级。
数据库升级前自动保存仓库外的本机元数据备份；不向NAS添加API或迁移NAS数据库。
升级后先检查原服务器档案，再验证LAN登录、真实目录与缩略图、四种布局、搜索和播放器。
字体跟随系统字体大小；建议先用默认 100%显示验收正常排版。App独立缩放设置尚未实现。

## 已知限制

- 主题切换后的系统栏灰底仍有明确失败回归，不能视为完整UI验收通过；将继续修复。
- Windows服务仅可保存档案，适配未完成。布局选择尚未持久化到每个档案。
- 复杂ASS字体/动画、全部真实音轨/PGS、外挂字幕、HDR/SDR、长时间/整片播放与性能仍未通过完整真机验收。
- 内嵌Tailscale实际外网100地址/子网、与Clash共存和切网尚未实测，不能保证这些项目已通过。
- 完整设置、平板/导航rail、TalkBack、诊断导出等仍在开发。
- 保存前的主题读取可能出现过渡帧，尚无逐帧启动证据。

正式版仍须通过批准计划中的全部真实门禁。请反馈手机型号、Android版本、连接方式、操作步骤和截图；不要提交密码/JWT/节点登录链接。
保留首版APK；如需降级涉及重装，不要直接卸载真实数据版本，完整档案导出界面尚未完成。
