## 用户配合：优先 USB 连接可信 Windows 测试机

1. 使用能传数据的USB线连接手机与已有Windows测试机，保持电脑在线、手机解锁。
2. 手机设置 → 我的设备/关于手机 → 详细信息与规格 → 连续点击OS版本进入开发者模式；不同系统界面名称可能不同，可搜索“开发者选项”。更多设置 → 开发者选项 → 打开USB调试。以实际系统提示为准。
3. 接入后允许本人信任电脑的RSA调试授权；“始终允许”只对私人可信机器选择。若默认仅充电导致无法识别，可切换文件传输并检查线材/驱动，不必预先安装整套Android Studio。
4. 无需root、解锁Bootloader、关闭系统优化或关闭安全保护。USB安装/安全调试额外开关仅在实际失败提示要求时处理，不预先扩大权限。
5. 告知代理“已接线、已允许调试”。后续由代理用既有SDK核验设备和应用状态；首次安装、权限、账号和节点批准等系统交互由用户操作。

无线调试是备选：Android11+在可信同一Wi-Fi下开启无线调试，通过配对码配对，再使用连接地址/端口；两个端口不同，重启/切网可能变化。配对码尽量在可信电脑本地输入，不写入聊天/仓库/日志。不得映射ADB端口到公网，不使用旧式TCP5555捷径。切换蜂窝网络测试时优先保留USB调试，关闭手机Wi-Fi但不打开USB共享网络，保证测试流量真走手机外网。

## 接入后的安全预检

使用已有SDK的ADB，先 `adb devices -l`，确认唯一授权目标；后续始终 `adb -s <confirmed-serial>`。仅私有记录型号/API/ABI/系统版本、应用版本与证书、运行显示能力。不要公开序列号、账号、设备地址或视频路径。

先检查 instrumentation 的 setup/teardown 与测试编排是否会清库、注销、清数据或改全局设置。个人手机上的已登录App不是可随意清理的测试fixture。签名不匹配不得默认卸载；优先同证书升级，必要时单独诊断包/applicationId及独立数据，但先说明其需重新登录/单独节点批准。不要复制节点身份或生产账号到fixture。

默认仅采集目标App诊断，避免通知/其他App/整机bugreport。不开root、不清数据、不删除现有Tailscale节点、不绕过TLS校验。测试结束可关闭调试/撤销本次配对，不撤销无关电脑授权。

## 下一会话功能切片

### M1 播放信息与可观测性

分开显示：

| 维度 | 所需信息 | 禁止推断 |
| --- | --- | --- |
| 片源 | 编码、分辨率、帧率、位深、色彩/传递特性、可获得的HDR元数据 | HEVC或10-bit不自动等于HDR |
| 设备能力 | 对应解码能力与当前显示HDR类型 | 支持HDR不代表正在输出HDR |
| 实际解码 | 请求策略、实际后端/解码器、回退原因 | 开启硬解请求不等于硬解已工作 |
| 输出 | 有依据的HDR直出、SDR映射、失败或未知 | 不凭文件名、屏幕变亮或截图标“已激活HDR” |

主界面保持克制，详情放播放器信息面板。源HDR标识与输出状态独立；接口无法可靠观测的状态显示“未知/未验证”，不伪造确定值。先查固定libVLC版本API，不能直接搬用另一个播放器的MediaCodec接口。

### M2 解码策略

补充用户可见的自动/硬件/软件策略入口，并独立显示实际模式。推荐默认自动；“硬件优先允许回退”和“强制硬件失败即报错”语义不同，实现前明确标签与契约，不能悄悄替用户决定。切换保持续播点、暂停状态、倍速和选轨，按引擎需要安全重建。软件解码不保证4K实时或HDR保真；不支持时明确说明。

### M3 视频质量与兼容入口

先检查现有NAS能力：原始文件直放只有一个源分辨率时显示“原画/源分辨率”，不能仅缩小Surface就称切换720p或节省流量。只有真实可用的多码率源或既有转码接口，才能提供对应质量。兼容转码必须显式选择并说明HDR/字幕/音轨影响，不静默替代原生。若需新增后端API或部署，另列范围和授权；客户端任务不授权修改NAS生产服务。

## 真机验收方法

1. 先核验当前安装包身份与用户已有网络成功场景，保留基线；不要求重复节点注册。新诊断包可能是独立节点，用户只对明确属于自己的新节点授权。
2. 使用有权使用的已知SDR/HDR短样本，记录私有hash及元数据；先测试首帧、真实画面、seek、轨道、字幕、取消与恢复。
3. HDR需同时检查片源、设备、实际解码链路与可获得的系统输出证据。截图/录屏可能被映射成SDR，不能证明屏幕真实HDR亮度。固定环境、亮度、系统增强设置，与可信播放器同片段对照只能作为辅助。取不到可靠输出证据则保留“待验证”，无需root。
4. 音频分开验证手机扬声器、耳机/蓝牙、轨道选择及音画同步；手机能响不证明TrueHD位流直通/多声道音响输出。
5. 短样本稳定后再执行60分钟及完整影片测试。先约定空闲窗口、蜂窝流量预算、音量、供电/亮度条件；记录首帧/seek/卡顿/丢帧/温度/耗电和网络。热警告或设备异常立即停止，不关闭温控。
6. 用户自行完成的外网通过保留为USER_VERIFIED；代理后续复验另记AGENT_VERIFIED。失败、资源阻塞、未测、设备不适用分别记录，不能合并为一张“全绿”表。
