# Android v0.3 预览交付

版本 0.3.0-preview，versionCode 4，Android 10+，arm64-v8a / x86_64。按用户要求先发布供自行验收，不以完整真机测试为发布前置条件；正式版门禁继续保留。

## 本次包含

- 内嵌 Tailscale 首次启动的权限/日志目录修复，登录状态决定退出按钮，支持官方登录链接、取消与重试。
- 保存当前档案、账号与目录，启动校验会话后恢复；连接表单分组圆角卡片。
- 文件页精简顶部，服务器信息移至设置；可点击末两级面包屑和完整路径跳转。
- 搜索顶部输入框，当前目录/包含子目录/全部三种范围，复用 NAS 搜索接口。
- 紧凑网格缩略图、统一目录/文件卡片、更新时间及文件详情。
- 无界网格采用独立列瀑布流：原比例缩略图不裁切，完整文件名不截断。
- 播放器加载/续播状态不再挤压视频区域；双击播放/暂停、长按默认 3×并恢复原倍速、0.1–5×自定义及长按速度配置。
- 搜索结果共用全部五种文件布局，沿用账号布局偏好。
- 缩略图磁盘缓存默认 500 MB / 最大 10 GB，超限 LRU，不做时间清除，支持手动清理。
- 播放缓存默认 1 GB / 0–10 GB，最多 2 MB 分块及一块有限预读，默认 24 小时清理（1–720 小时可配置），定时/手动清理保护在播文件。系统后台调度可能延后执行。
- 图片查看默认原图，支持高/中/低及缩放；图片缓存默认 1 GB / 0–50 GB，当前账号缓存列表支持查看及单项删除。高为原文件在客户端解码限长 2560，中/低复用 NAS 1080 big 与 512 contain 预览，不新增服务端质量 API。

## 尚未完成或验证

服务端搜索历史仍待支持，现有 NAS 未提供该 API；本次不新增后端数据库。复杂 ASS 样式/字体及首次解码问题仍在修复。新增缓存、手势、图片及搜索布局已实现，预览不等待完整真机验收，不把编译或逻辑单测当作体验验收。

构建/lint 和此前聚焦回归有记录；本次瀑布流修正仅完成编译与 lint，不宣称视觉验收通过。真实手机 Tailscale 登录、100/子网地址、外网、Clash 共存、全部音轨/PGS、HDR/SDR 与长时间性能未完成验收。

## 构建和发布

手动运行 Android preview package 工作流，只构建安装包，不等待模拟器矩阵。产物记录已推送源码 SHA，下载后使用仓库外的原专用证书签名，检查版本、ABI、签名和对齐，再发布 GitHub prerelease。此包为 debug 预览构建，不是正式 release。

保留上一版 APK；沿用原签名可覆盖安装。当前状态 schema 已升级，不能把旧 APK 直接覆盖回来；导出/降级工具尚未完成。不要卸载后再装以尝试修复登录，这会删除本地档案与状态。
