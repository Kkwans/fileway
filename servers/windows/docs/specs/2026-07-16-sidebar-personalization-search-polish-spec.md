# 侧边栏个性化、搜索筛选与空状态优化方案

## 目标

本轮只修改源码、测试、提交并推送，不部署：

1. 用户卡片与一级模块共用同一水平基线。
2. 删除独立“设置”，新增可折叠的“系统选项”模块，收纳我的文件、搜索、新建文件夹、新建文件。
3. 侧边栏全部可排序项支持拖动，并把顺序保存到当前用户的本地数据库记录。
4. 修复搜索和标签筛选页重复侧边栏偏移造成的内容不居中。
5. 搜索结果支持图片、音频、视频、PDF、Markdown、配置和代码类型筛选。
6. 空文件夹状态居中显示，面包屑首页图标严格垂直居中。

## 数据方案

- 在现有用户记录中新增 `SidebarPreferences` JSON 字段。
- 继续复用 `/api/users/{id}` 的用户读取和局部更新能力，不增加数据库和独立接口。
- 收藏及收藏分组继续使用已有收藏排序接口；其他顺序统一由侧边栏偏好存储维护。
- 偏好字段包括：
  - 一级模块顺序；
  - 系统选项顺序；
  - 标签顺序；
  - 目录分类及分类内路径顺序；
  - 存储卷顺序。
- 新增或当前不可见的项目自动追加，已删除的历史 ID 自动忽略。

## 默认结构

1. 用户
2. 系统选项
3. 收藏夹
4. 标签
5. 目录分类
6. 存储卷
7. 登出

## 搜索行为

- 搜索前选择类型：写入搜索条件，提交后由后端筛选。
- 未指定类型完成搜索后：切换类型只过滤当前结果，不重复访问磁盘。
- 已指定类型完成搜索后：切换类型会替换搜索条件并重新搜索。
- 复合类型由后端映射到扩展名集合；单一扩展名仍沿用原有 `type:<扩展名>` 行为。

## 验收标准

- 所有可见侧边栏一级模块和指定二级条目均可拖动排序，刷新和重新登录后顺序保持。
- 用户 A 的排序不影响用户 B。
- 用户卡片、系统选项和其他一级模块左右边界一致。
- 搜索与标签筛选结果区域在主内容区水平居中，不出现额外左侧空白。
- 搜索前后均能使用完整文件类型筛选。
- 空文件夹提示位于内容区正中心；面包屑首页图标与文字、箭头垂直居中。
