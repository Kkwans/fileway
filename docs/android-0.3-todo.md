- [ ] F01 产品流程：上述基础体验通过；新增档案 → 内嵌登录 → NAS 登录 → 浏览/搜索 → 原生播放/选轨 → 续播 → 重启恢复；实际用户设备走完整流程。

- [ ] F03 网络：手机内嵌节点通过 100 地址及批准子网在蜂窝或外地 Wi-Fi 播放；记录 direct/relay/DERP 与播放器字节；断网/切网/重连、Clash 共存。不用“没有 VpnService”代替共存实测。
